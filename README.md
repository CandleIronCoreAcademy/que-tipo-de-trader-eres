# ¿Qué tipo de trader eres?

Interactive educational resource developed by **Candle Iron Core Academy** as part of its trading education materials.

This questionnaire is designed to help students identify characteristics of their trading profile based on their preferences, decision-making, and approach to the market.

## Candle Iron Core Academy

Trading education built on **Objectivity, Probability & Simplicity**.
